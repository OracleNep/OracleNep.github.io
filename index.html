Research & Practice

From source review and reproducible findings to remediation and retesting.

Application Security

I review Java / Spring applications by tracing request entry points, permission checks, data flow, and dangerous operations. My tooling work connects source context with Semgrep / CodeQL findings and SARIF reports.

My practical experience includes authorized vulnerability research, incident triage, host-security checks, impact assessment, and remediation follow-up.

AI Agent Security

I study where agents cross trust boundaries: tool execution, MCP permissions, local control planes, and approval flows. I also work on recovery behavior, evidence records, and human review in agent-assisted security workflows.

Research notes document prerequisites and verification limits alongside findings.
