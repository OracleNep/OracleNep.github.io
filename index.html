JavaSecAtlas

A Java / Spring audit assistant built with SoybeanSeclab, used for audit preparation, rule prototyping, and report generation.

Java / Spring Audit workflow SARIF / HTML
  • Recognizes Maven / Gradle projects and extracts Spring routes with selected authorization annotations.
  • Includes heuristic rules for SSRF, XXE, SpEL, path traversal, and file upload cases.
  • My work covered project recognition, route extraction, rule design, report generation, and review workflow.
