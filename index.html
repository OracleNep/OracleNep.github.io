项目与贡献

开源项目和上游 PR 更适合展示工程能力：能运行、能复盘、能追踪提交和 review 过程。

JavaSecAtlas

面向 Java / Spring 代码审计的自动化工作台，用于白盒审计准备、规则原型验证和报告整理。

Java / Spring SAST 辅助 SARIF / HTML
  • 支持 Maven / Gradle 项目识别、Spring 路由和权限注解提取。
  • 内置 SSRF、XXE、SpEL、路径穿越、文件上传五类启发式规则。
  • 参与项目识别、路由提取、规则设计、报告生成与 Agent 复核流程设计。

PHP php-src

参与 PHP 官方源码仓库上游维护，覆盖 HTTP 请求体解析配置校验和 ext/intl 文档注释维护。

C PHPT Upstream
  • #22261 已合入，维护 ext/intl 错误处理约定文档与测试注释。
  • #22223 围绕 request_parse_body() 与 max_input_vars 的输入处理一致性提交补丁。
  • 沉淀大型开源项目 CI、Review、最小化补丁和测试补充经验。

Phantom

SoybeanSeclab 团队开源浏览器安全扩展，面向 SRC 漏洞挖掘中的页面信息收集场景。

JavaScript Browser Extension SRC 辅助
  • 支持基础扫描、深度递归扫描、批量 API 测试、结果导出和自定义正则配置。
  • 可用于前端接口梳理、敏感信息发现、JS 资源分析和授权测试前期资产整理。
  • 作为团队工具生态的一部分，为 SRC / Web 资产分析流程提供辅助能力。
