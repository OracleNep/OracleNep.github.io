JavaSecAtlas

A Java / Spring audit workbench developed with SoybeanSeclab for rule prototyping, SARIF normalization, and report preparation.

Java / Spring Audit workflow SARIF / HTML
  • Recognizes Maven / Gradle projects and extracts Spring routes and selected permission context.
  • Provides heuristic checks for SSRF, XXE, SpEL, path traversal, and file upload cases.
  • Connects repeatable findings with report generation and human review.

VulnClaw

An AI Agent security testing tool that combines MCP tools and Skill orchestration for authorized asset mapping, verification, and report drafting.

AI Agent MCP Authorized Testing
  • Explores recovery behavior when an automated task reaches an exception or fallback path.
  • Emphasizes tool permissions, run records, false-positive review, and human confirmation.
  • Keeps AI output as supporting evidence rather than the final security decision.

Phantom

A SoybeanSeclab browser extension for early-stage frontend asset mapping and signal collection in authorized testing.

JavaScript Browser Extension SRC workflow
  • Supports basic and recursive scanning, batch API checks, export, and custom regex rules.
  • Useful for frontend API mapping, JavaScript review, and scope control before manual testing.
  • Maintained as part of a broader security tooling workflow.
